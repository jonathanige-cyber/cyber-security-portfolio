# Network Reconnaissance Lab

## Objective

Learn how network reconnaissance works and understand how devices and services can be identified on a network.

## Skills Demonstrated

- Network discovery
- IP addresses
- Ports
- TCP and UDP
- Basic service enumeration
- Nmap
- Network security

## Environment

This lab will be completed in an isolated virtual machine environment.
